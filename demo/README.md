# Screenshot demo

```sh
npm run demo
```

Open http://127.0.0.1:4173 in Chrome. Choose X or LinkedIn, a display style, and settings.

Click **Capture view** to hide the toolbar; press Escape to restore it. The canvas is 1280 × 800. Use 100% browser zoom and a window large enough to show it at full size.

The demo uses the extension's UI with fictional posts and preset scores. It makes no API calls and isn't included in the extension ZIP.

Stop the server with Ctrl+C.
